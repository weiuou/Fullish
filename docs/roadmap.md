# 路线图

## 已完成：部署基础

- NoneBot2 服务骨架、健康检查和构建版本标识。
- GitHub PR 检查、不可变镜像发布、腾讯云受限 SSH 部署。
- 实测首次发布、合并后自动更新，以及回滚与恢复最新版。
- 提供 TAT 可选接入、开发与部署文档。

## 下一步：群聊闭环

1. 在测试群验证 QQ 官方接入的全量群消息权限。
2. 在入口过滤私聊，再处理群消息和发送回复。
3. 添加按群调度、上下文与可替换模型接口。
4. 实现能选择沉默的发言策略，并建立合成群聊回放。

## 后续：自然聊天与开源协作

- 版本化人格、多人指代和过时回复处理。
- 带来源和群作用域的记忆；按需引入 PostgreSQL、迁移与备份。
- 自然度、误插话、漏回应、延迟与成本评测。
- 稳定插件接口，确定开源许可证和维护者分工。

架构边界见 [架构说明](architecture.md)。
