# 绘图流程

先确定图要回答的一个问题与真实数据，再选择图形。关系和流程使用 Mermaid；精确位置、
数学与数据图使用 SVG；小型说明卡片使用 HTML/CSS。缺少的数据明确标为未知，不补造数字。
按需读取 flowchart、data 或 layout 指南。用中文短标签，简短标题，最多一个主结论。
首次调用 visualize_render 后必须查看实际图片；检查文字是否清晰、箭头是否正确、是否截断。
每任务最多两次渲染，第二次用于有目的的修正。用 fullish_reply 登记所选 artifact_id，
由 Fullish 决定实际投递；工具成功不表示 QQ 已收到。
